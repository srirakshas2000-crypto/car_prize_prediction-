🚗 Car Price Prediction
Machine learning model to predict used car prices using Random Forest, Python and Scikit-learn.
📌 Project Overview
This project predicts the selling price of a used car based on features like brand, fuel type, kilometers driven and more using a Random Forest Regressor.
📂 Dataset Features
brand - Car brand (Toyota, BMW, Honda, etc.)
year - Manufacturing year
km_driven - Total kilometers driven
fuel - Petrol / Diesel / Electric
transmission - Manual / Automatic
max_power - Engine power in BHP
Target - price (selling price in ₹)
⚙️ Technologies Used
Python
Pandas, NumPy
Scikit-learn
Matplotlib, Seaborn
Jupyter Notebook
🤖 Model Used
Random Forest Regressor
100 estimators
R² Score: 0.89
Handles non-linear relationships well
